## Overview

EDDI monitors Elite Dangerous game events via the Journal API and responds with contextual voice narration, mission briefings, system information, and spoken alerts for traffic, cargo, and bounties.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **EDDI** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Event Narration** | Spoken commentary triggered by hyperjumps, docking, and combat |
| **System Briefings** | Voice summary of destination economy, faction, and security status |
| **Mission Alerts** | Audible reminders for expiring missions and target proximity |
| **Custom Scripts** | User-authored personality scripts with full variable access |
